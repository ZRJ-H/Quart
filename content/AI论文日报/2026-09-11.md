### [GPU-CFR：将博弈编译为静态数据流并用 CUDA Graph 重放，实现 80 倍加速的反事实遗憾最小化](https://arxiv.org/abs/2609.11923v1)

- **原标题**：GPU-CFR: 80x Faster Counterfactual Regret Minimization by Compiling the Game to Static Dataflow and CUDA Graph Replay
- **来源与时间**：arXiv · 2026-09-10T17:58:14+00:00
- **作者/分类**：Boning Li、Longbo Huang · cs.DC、cs.AI、cs.GT、cs.MS、cs.PL
- **研究问题**：CFR 在 GPU 上受限于内核启动与框架调度开销，此前 GPU 实现难以超越优化后的 CPU 代码，如何消除这些开销并保持更新规则不变是核心问题。
- **方法**：作者提出 GPU-CFR 编译器与运行时，将任意博弈一次性编译为静态数据流，包括扁平边与信息集数组、预计算索引与按深度分批的遍历；并采用静态机会折叠、深度级执行块与双通道可达缓冲区，再用 CUDA Graph 记录并重放迭代。
- **实验结果**：静态编译将框架操作数最多减少 18.1 倍；在单张 A100 的八款博弈套件上，GPU-CFR 比最快既有 GPU CFR 快 29.8 至 80.4 倍，在四款最大博弈上比 LiteEFG 快 14 至 258 倍，八线程 CPU 上比 GPU 基线快 2.2 至 51.1 倍。
- **局限**：证据未给出全部博弈上的完整加速数据，也未说明编译与图捕获在极小博弈或频繁更换博弈场景下的摊销表现，相关适用边界仍需进一步验证。
- **工程价值**：该方案把博弈结构预编译与 CUDA Graph 重放结合，为在 GPU 上高效运行大规模 CFR 提供了可落地的编译与运行时工程路径。
- **价值点**：该工作表明，将博弈结构静态化并借助 CUDA Graph 重放，可把 CFR 从 CPU 优势负载转变为 GPU 优势负载，为大规模博弈求解提供了可复用的编译与运行时思路。

- **实验结果**：所推导的误差界适用于广泛的损失函数、标签空间与随机标注情形，配套估计器具有集中保证，DataShifts 可在多数应用中量化分布偏移并估计误差界。
- **局限**：证据未给出具体实验数据、估计误差数值或与既有方法的定量对比，因此该框架在真实高维数据上的实际精度与可扩展性尚不明确。
- **工程价值**：DataShifts 算法为在真实应用中量化分布偏移并估计学习误差界提供了可直接使用的工具，有助于在部署前评估模型在偏移下的风险。
- **价值点**：该工作把概念偏移推广为可估计的 γ*-概念偏移，并给出统一误差界与配套算法，为分布偏移下的学习误差分析提供了更贴近实践的理论工具。

### [数据稀缺与模型稀疏：混合专家模型对重复数据过拟合更严重](https://arxiv.org/abs/2609.11917v1)

- **原标题**：Data Scarcity and Model Sparsity: Mixtures-of-Experts Overfit More to Repeated Data
- **来源与时间**：arXiv · 2026-09-10T17:57:33+00:00
- **作者/分类**：Atindra Jha、Margaret Li、Jure Leskovec、Percy Liang、Luke Zettlemoyer · cs.LG、cs.CL
- **研究问题**：数据重复对稠密 Transformer 的影响已有研究，但对 MoE 等稀疏架构的影响 largely 未被探索，稀疏性与数据重复之间是否存在不利交互尚不清楚。
- **方法**：作者在单域与多域数据混合、不同专家数量与粒度的 MoE 设定下改变数据重复率，覆盖 80M 至 1B 激活参数（总计 8.5B）的模型，并实验既有正则化方法作为补救，同时分析高重复率下 MoE 过拟合的内部机制。
- **实验结果**：MoE 在数据重复下退化更快且随稀疏度增强，由总参数决定；80M 稠密模型重复超过 8 倍退化极小，MoE 在 4 倍即受损，32 倍后性能低于稠密模型；强掩码正则化下 MoE 在重复超过 64 次时仍可优于稠密模型，但无方法完全匹配全唯一数据。
- **局限**：证据未给出具体任务、评测指标与完整数值表，也未说明结论在更大规模模型或不同模态数据上是否成立，因此外推需谨慎。
- **工程价值**：该结果提示在必须重复训练数据的工程实践中，MoE 需要更强的掩码类正则化，并应关注专家特化与路由早期稳定带来的过拟合风险。
- **价值点**：该工作揭示了稀疏性与数据重复之间的不利交互，给出过拟合核心机制与潜在补救的证据，并指出通过打断记忆模式来减少参数过度特化的未来方向。
