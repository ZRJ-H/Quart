- **来源摘要**：Large language models reinvent the wheel all the time. They conflate task-solving with the execution of the solutions, which forces them to solve every problem from scratch. ### [论 ReLU 网络集合的非闭性](https://arxiv.org/abs/2611.09887v1)

- **原标题**：On the \(non-\)closedness of the set of ReLU networks

- **核心摘要**：论文证明：对有界连通开集 Ω⊂R^d，至多 N 个神经元的单隐藏层 ReLU 网络集合在 W^{1,p}\(Ω\) 中是弱闭的。由此，该空间上每个强制性、弱下半连续的泛函都能在集合上取到最小值，覆盖凸被积函数的 Deep Ritz 方法、Sobolev 训练和 Lipschitz 学习。论文还证明，当权重衰减参数趋于零时，正则化问题的极小点（沿子列）收敛到参数范数最小的极小点。另一方面，作者证明两个隐藏层、宽度有界的 ReLU 网络集合在 W^{1,p}\(Ω\) 和 C\(Ω 闭包\) 中都不闭，这否定了 Petersen、Raslan 和 Voigtlaender 的一个猜想。
- **研究问题**：论文考察 ReLU 网络集合在 Sobolev 空间中的闭性，以及由此决定的变分能量极小点存在性，并检验双隐藏层网络集合闭性的既有猜想。
- **方法**：对有界连通开集 Ω 上的单隐藏层、至多 N 个神经元的 ReLU 网络集合，证明其在 W^{1,p}\(Ω\) 中弱闭；分析权重衰减参数趋于零时正则化问题极小点的收敛；构造双隐藏层、宽度有界网络集合的非闭性证明。
- **实验结果**：单隐藏层 ReLU 网络集合弱闭，使强制性、弱下半连续能量可取到最小值，覆盖凸被积函数的 Deep Ritz 方法、Sobolev 训练和 Lipschitz 学习；权重衰减趋于零时极小点沿子列收敛到参数范数最小的极小点；双隐藏层有界宽度网络集合在 W^{1,p}\(Ω\) 与 C\(Ω 闭包\) 中不闭，否定 Petersen、Raslan 和 Voigtlaender 的猜想。
- **局限**：结论限定于单隐藏层且神经元数不超过 N 的 ReLU 网络，以及有界连通开集 Ω；双隐藏层结果针对宽度有界的情形。

- **核心摘要**：论文从图像的 Gaussian jet 出发，把它视为分级向量空间：尺度为 λ 的膨胀将 k 阶导数乘以 λ^{-k}。作者指出局部分级卷积恰为齐次微分算子，局部特征具有膨胀不变性当且仅当它通过尺度归一化 jet 分解，或者在不使用尺度时通过到分级加权球面收缩的映射分解。在未知高斯模糊下，该收缩只发生尺度变化，而尺度归一化 jet 会获得一个任何径向归一化都无法消除的分级因子。在零 jet 处，该收缩能区分径向归一化和连续分类器无法区分的图像族；基于该收缩构建的网络对不变特征具有通用性。在 MNIST 上，该网络在两像素模糊下保持 88.4% 准确率，而同一网络在尺度归一化导数上为 66.2%；在 Lindeberg 的高斯导数网络中，该收缩把该模糊下的准确率从 91.5% 提升到 95.1%。
