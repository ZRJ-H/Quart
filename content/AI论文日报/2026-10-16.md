### [静态技能不一致为何不等于运行时风险：LLM Agent 执行的行为分析](https://arxiv.org/abs/2610.18927)

- **原标题**：Why Static Skill Inconsistencies Do Not Equate to Runtime Risks: A Behavioral Analysis of LLM Agent Execution
- **来源与时间**：arXiv · 2026-10-15T04:00:00+00:00
- **作者/分类**：Fengrui Fan, Huahao Wang, Jingyi Fang, Yutao Hu, Yueming Wu, Deqing Zou · cs.AI
- **研究问题**：静态审计能发现技能包中的契约不一致，但静态缺陷数量能否可靠反映 LLM Agent 在真实执行中的性能退化，此前缺乏严格证据。

- **实验结果**：研究量化了已解决缺陷对运行时表现的实际影响，表明静态不一致数量与真实性能退化之间不能简单等同，需通过可执行任务评测才能判断风险。
- **局限**：证据来自 575 个技能、49 个任务与三种 LLM 的受控设置，任务与模型覆盖面有限，结论向其他技能生态、任务类型与模型版本的推广仍需更多验证。
- **工程价值**：为 Agent 技能平台提供了可执行任务级回归评测的参考流程，可用于在发布前评估技能不一致的真实风险，而非仅依赖静态审计告警。
- **价值点**：为 Agent 技能治理提供了从静态审计转向运行时验证的实证依据，有助于实践者更理性地分配技能修复与审核资源。

- **实验结果**：在协同科学家设置下，开发版本系统提交的单篇研究论文被 ALIFE 2026 接收；系统还被全自主应用于机器学习开放问题求解，展示跨领域计算研究的发现能力，消融表明可靠科学自主性依赖跨 Agent 编排层而非仅基础模型能力。
- **局限**：证据主要来自单一系统的内部实验与消融，论文接收与开放问题演示的样本量有限，跨领域复用效果与全自主发现的可靠性仍需更广泛的外部验证。

- **价值点**：为计算研究提供可跨领域复用的多 Agent 编排范式，并给出协同与全自主两种使用路径的实践参考。

### [超越方程搜索：SCOPE 与 ClosureBench 的猜想引导发现](https://arxiv.org/abs/2610.18938)

- **作者/分类**：Yuxiao Hu, Qian Li, Ding Wang, Siheng Chen, Linfeng Zhang, Jinyue Yan, Yuntian Chen · cs.AI、cs.LG
- **研究问题**：多数符号回归方法只优化候选方程，但方程拟合提升无法判断其背后的科学猜想应保留、修正还是拒绝，且现有基准主要评估恢复的表达式，忽视研究过程中建立的证据与科学结论。

- **实验结果**：相比多种基线，SCOPE 在 ClosureBench 与一个真实科学发现案例上取得更高的方程精度，同时产生更准确、可靠且有效的科学发现；ClosureBench 还提出证据忠实性、机制洞察与实验有效性三项过程指标。

- **价值点**：为方程发现提供了以猜想为中心的多 Agent 框架与过程导向基准，有助于把符号回归评价从拟合精度推进到科学结论质量。

- **核心摘要**：该研究主张以推断准确率来认证协调者模块是错误的，原因有二：其一，行动所需的准确率取决于错误行动的代价，门槛属于部署而非模块；其二，模块错误很少独立，依赖具有方向性，正相关错误在损害重叠处有益、在损害叠加处有害，因此准确率阈值会朝可预测方向失效。作者在任务分配、Level-Based Foraging 与 Hanabi 中注入错误，使用训练模块、贝叶斯模块与五个语言模型并加入人类判断进行检验，发现准确率在两个方向上都失效。
