    - 摘要：论文指出统一多模态模型在图像生成上难以有效利用基于语言的思维链推理，因而未能继承大语言模型中的测试时扩展和细粒度可控性。作者将原因归结为模态不匹配：推理发生在离散 token 空间，而图像生成在连续空间进行。为此提出 LARC 框架，在连续隐藏状态上推理以缓解 token 级瓶颈。训练分两阶段：课程式监督微调逐步把 token 级推理转为潜在推理，随后用信息增益强化学习在无真值监督下自我演化潜在推理。在多个文生图基准上，LARC 提升了生成质量、提示跟随和组合保真度；在 GenEval 上比 BAGEL 高 7 个百分点，并表现出测试时扩展行为，在并行和串行测试时扩展策略下均优于基于 token 的生成。 结果：在多个文生图基准上一致提升生成质量、提示跟随和组合保真度；在 GenEval 上比 BAGEL 高 7 个百分点，并展现测试时扩展行为，在并行和串行测试时扩展策略下均优于基于 token 的生成。
  - [Flide: Accelerating Decision Inference with Exact State Forking](https://arxiv.org/abs/2610.42148v1)
    - 摘要：Decision models such as Jev have emerged as a highly promising paradigm for LLM agent systems, providing lightweight and reliable categorical reasoning for rapid System One execution. However, existing generation-oriented inference engines fail to support these workloads effectively, suffering from severe prefix recomputation overheads or distorted output probabilities. To address this challenge, we propose Flide, an efficient and exact inference engine that decouples the logical tree structure of a decision request from its physical execution within a single flattened token stream. Through ForkAttention, Flide navigates request dependencies using GPU-resident indices across both standard attention and recurrent Gated DeltaNet layers, guaranteeing in exact arithmetic that every query branch evaluates identically to an isolated forward pass. By expressing branch topologies directly in GPU-resident metadata, Flide accommodates diverse request mixtures with a compact set of pre-recorded execution graphs while enabling expanding agent histories to resume from checkpoints saved in earlier passes. Extensive evaluations on public hybrid and decision models demonstrate that Flide answers queries up to 9.5 times faster than vLLM and SGLang while staying closest to a float32 reference in total variation distance. By unifying physical execution throughput with mathematical exactness, Flide establishes a principled foundation for scalable, latency-critical decision intelligence in agent systems.
  - [Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention](https://arxiv.org/abs/2610.42147v1)
    - 摘要：Agentic workflows are increasingly shifting towards long-horizon tasks, such as open-ended scientific work, where models benefit from long context windows. However, at ultra-long context \(above 1M tokens\), full attention is prohibitively expensive. A promising approach is sparse attention, in which a dedicated indexer selects a subset of keys for the attention. Yet current methods of indexing either still have quadratic cost in context size or lose accuracy at ultra-long context scale. We address this with Latent Sparse Attention \(LSA\), an efficient attention method that maintains accuracy at ultra-long context. In LSA, keys are hierarchically clustered in a learned latent space, and queries score the hierarchy of clusters instead of scoring every key, making prefill, decode and training faster at long context. We propose two variants, Distilled-LSA \(D-LSA\), which can be applied to pre-trained models via distillation, and Native-LSA \(N-LSA\), which is trained natively on the next-token loss alone. On GLM-5.3-FLASH \(QWEN-3.8-27B\) at 10M tokens, D-LSA speeds up one attention layer by 22.7x \(72.4x\) in prefill and 4.6x \(42.5x\) in decode over its original sparse attention \(full attention\), while keeping similar accuracy across a variety of tasks. N-LSA matches the accuracy of full attention with a training speedup of 1.6x per layer at 128k tokens. LSA offers practical and efficient attention for models to benefit from ultra-long context.

We also introduce OpenPerov, an expert-informed language-model framework that learns from expert-calibrated evidence records reconstructed from 4,532 articles; these records link experimental strategies, controls and observations to mechanistic interpretations.   - [TopoQuant: Topological Framework to Characterize Behavioral Shifts in Quantized Large Language Models](https://arxiv.org/abs/2611.00631v1)
    - 摘要：Post-training quantization \(PTQ\) reduces the com putational cost of large language models \(LLMs\), but it can introduce internal structural and behavioral changes that are not captured by traditional metrics such as accuracy and per plexity. We present TopoQuant, a topological framework that uses topological data analysis \(TDA\) to quantify structural drift in self-attention weights and relate it to behavioral changes in quantized LLMs. Across four LLM families and multiple quantization levels, we show that topological drift remains stable at moderate compression levels but increases sharply below 4 bit precision, closely tracking declines in attention agreement. Our results reveal a strong relationship between topological drift and attention agreement, indicating that structural changes in model parameters closely reflect behavioral degradation under quantization. We further demonstrate that topological features can accurately predict attention consistency using lightweight machine learning models, achieving R2 scores of up to 0.85. Predicting attention agreement enables efficient assessment of be havioral consistency in quantized LLMs, allowing quantization induced degradation to be detected without running expensive downstream tasks. The results indicate that topological drift pro vides an efficient early-warning signal for quantization-induced degradation and can help identify safe compression limits without extensive downstream evaluation.
